# PowerPlant Energy Prediction

Problem Statement: Predicting the electrical energy output of a power plant is critical for grid stability, efficient load scheduling, and operational cost optimization. However, power output varies dynamically depending on ambient environmental factors like temperature, pressure, and humidity.

Solution: The objective of this project is to build a machine learning model that accurately estimates the net hourly electrical energy output ($PE$) using ambient variable measurements.

## Tech Stack
- Data Science: NumPy, Pandas, Matplotlib, Seaborn.
- Machine Learning & Deep Learning: Scikit-Learn, PyTorch.
